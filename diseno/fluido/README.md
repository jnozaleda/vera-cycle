# Imágenes fluidas de Hera

Generadas por código con la paleta de la marca (sin fotos ni licencias). Validadas por Noza el 2026-10-09.

- `generar.py` — `python3 generar.py` regenera todo en esta carpeta (necesita numpy y Pillow; semillas fijas).
- `*.png` — maestros sin pérdida · `*.webp` — versiones ligeras para la web.
- `muestras.html` — hoja de muestras con cada imagen aplicada (banda final, fondo de portada, pastillas).

En la web se usan (copias en `portada/fluido/`): `via-lactea-atardecer` (banda final y pastilla de «Tu bebé»),
`seda-melocoton` (fondo detrás del móvil y pastilla de «Posparto») y `seda-rosa` (pastilla de «Embarazo»).
Motivo: la Vía Láctea del mito de Hera, formada por su leche derramada.
